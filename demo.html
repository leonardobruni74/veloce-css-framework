Perché Scegliere Veloce?

100% CSS Puro

Nessuna dipendenza JavaScript. Solo CSS pulito e performante per il massimo controllo.

Semantico e Italiano

Classi in italiano chiare e semantiche. Naming coerente e intuitivo per sviluppatori italiani.

Altamente Compatibile

Supporto per tutti i browser moderni. CSS standard senza proprietà sperimentali.

Veloce è un framework CSS moderno e leggero, creato per sviluppatori italiani. Utilizza naming semantico in italiano e fornisce tutti gli strumenti necessari per creare interfacce web responsive e moderne.
Semplicemente scarica il file fast.css e includilo nel tuo progetto HTML con un tag link. Non sono necessarie dipendenze JavaScript o altri file.
